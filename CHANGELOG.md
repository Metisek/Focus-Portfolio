# Changelog

Changes from before the first GitHub release are listed by date; the version label stayed at "1.1" during that time.

## 1.1 (2026-11-10, first GitHub release)

- Updates from GitHub releases (Plugin Update Checker 5.7, `Update URI` header). A GitHub Action builds the release from a `vX.Y` tag.
- "GitHub" and "☕ Postaw kawę" (buy me a coffee) links in the plugin list and on the Instrukcja (manual) screen.

## 2026-11-10 (database schema 1.3.0)

- **Colors and layout**
  - Colors now come from the theme.
  - The dark variant is gone; there is a new "tiles" variant.
  - Min./max. columns, an even bottom edge for masonry, and covers that fill their tiles.
- **Lightbox and links**
  - The lightbox shows photos in the same order as the grid.
  - Photo links (`#foto-<file>`) are computed on the server (`FP_Links`).
- **Folder structure**
  - New schemes: `years`, `dated` (dates in folder names), and months inside year folders.
  - Configurable start of the "photo year" instead of a fixed academic year.
  - Category titles, slugs and order are stored in the Structure settings, so existing URLs stay the same.
- **Photographers and credits**
  - The photographers registry no longer needs an "add" step.
  - Deleting a person can also remove their credits from photos.
  - New settings: an organization credit to ignore (EXIF) and words for OCR to skip.
- **Explorer**
  - Fixed an overlay that blocked clicks.
  - Recursive counts, inbox previews, a toggle for copies generated by WordPress, and a context menu.
- **Translations**: visitor-facing text in EN, DE, ES, FR and IT. The default follows the site language, and you can force a language.
- **New "Focus Portfolio – Zdjęcia" photos widget** (Elementor, block `focus/photos`, shortcode `[focus_photos]`)
  - Modes: random, best, one per recent event, from folders, picked.
  - Views: rows, masonry, grid, collage, strip.
  - Remembers the drawn photos, and a "bag" mode avoids repeats.
- **Generalized**: removed hard-coded, club-specific behavior.

## 2026-11-07

- The author filter counts photos across all selected periods and has a "no credit" entry.

## 2026-11-06 (database schema 1.2.0)

- **Dashboard**: a "Focus Portfolio" menu, roles and capabilities (portfolio editor), an explorer with trash, a structure wizard and a photographers registry.
- **Data**: a `_portfolio.json` file in every folder.
- **Visitors**: pagination, filters and sorting.
- **Elementor**: the widget has Content, Layout and Style tabs.

## 2026-11-04 (1.1.0)

- First deployment.
- Elementor widget and `focus/portfolio` block, covers, OCR for photo credits (tesseract.js), a period filter, and original-format images in the lightbox.
